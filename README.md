
# Splay Trees – Understanding Self-Adjusting Binary Search Trees

A collaborative Data Structures learning project exploring **Splay Trees**, their structure, rotation operations, algorithms, complexity and applications.

## 📖 About the Project

A Splay Tree is a self-adjusting Binary Search Tree (BST) in which the recently accessed node is moved to the root through a sequence of rotations called *splaying*.

This project focuses on understanding how Splay Trees work, how their rotations maintain the BST property, and how they improve access efficiency through self-adjustment.

## 🎯 Objectives

- Understand the fundamentals of Trees, Binary Trees and Binary Search Trees.
- Explore the properties and structure of Splay Trees.
- Understand different rotation operations.
- Study searching, insertion and deletion.
- Analyse time complexity and amortized performance.
- Explore practical applications and limitations.

## 📚 Topics Covered

1. Introduction to Trees and Binary Search Trees
2. Introduction and properties of Splay Trees
3. Splay Tree rotation operations:
   - Zig
   - Zag
   - Zig-Zig
   - Zag-Zag
   - Zig-Zag
   - Zag-Zig
4. Searching in Splay Trees
5. Insertion in Splay Trees
6. Deletion in Splay Trees
7. Algorithms and flowcharts
8. Time complexity and amortized analysis
9. Advantages and disadvantages
10. Applications of Splay Trees
11. Comparison of BST, Splay Tree and AVL Tree

**Note:** A single operation can take O(n) time in the worst case, but Splay Trees provide O(log n) amortized time per operation over a sequence of operations.

## 💡 Key Takeaway

Splay Trees demonstrate how a data structure can adapt to its usage patterns. By moving recently accessed nodes closer to the root, they make frequently accessed elements more efficient to reach over time.
